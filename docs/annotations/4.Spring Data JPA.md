# Spring Data JPA（Repository）

| 註解 | 次數 | 用途 |
|------|------|------|
| `@Query` | 32 | 在 Repository 方法上自己寫 JPQL / SQL |
| `@Param` | 59 | 把方法參數對應到 `@Query` 裡的 `:名稱` |
| `@Modifying` | 6 | 搭配 `@Query`，表示這是 UPDATE / DELETE，不是查詢 |
| `@Lock` | 4 | 查詢時鎖住資料列，避免同時修改（`OrderRepository`、`PaymentRepository`、`ProductVariantRepository` 扣庫存） |
| `@EntityGraph` | 2 | 查詢時順便把關聯資料一起撈出來，避免 N+1 查詢 |
| `@PageableDefault` | 10 | 分頁參數的預設值（例：預設每頁幾筆、依什麼排序） |
