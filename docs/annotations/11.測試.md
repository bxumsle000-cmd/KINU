# 測試用

| 註解 | 次數 | 來源 | 用途 |
|------|------|------|------|
| `@Test` | 96 | JUnit 5 | 這是一個測試方法 |
| `@BeforeEach` | 9 | JUnit 5 | 每個測試前都先執行 |
| `@AfterEach` | 1 | JUnit 5 | 每個測試後都執行 |
| `@SpringBootTest` | 9 | Spring Boot Test | 啟動完整的 Spring 來測試 |
| `@WebMvcTest` | 3 | Spring Boot Test | 只啟動 Controller 那一層來測試 |
| `@MockitoBean` | 13 | Spring Test | 用假物件（mock）取代 Spring 裡的某個 bean |
| `@MockitoSpyBean` | 1 | Spring Test | 包住真的 bean，可以監看或改寫部分行為 |
