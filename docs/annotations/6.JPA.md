# JPA（Jakarta Persistence）：Entity 對應資料表

| 註解 | 次數 | 用途 |
|------|------|------|
| `@Entity` | 19 | 這個類別對應一張資料表 |
| `@Table` | 19 | 指定資料表名稱，例：`@Table(name = "orders")` |
| `@Id` | 19 | 主鍵欄位 |
| `@GeneratedValue` | 18 | 主鍵由資料庫自動產生（自動遞增） |
| `@Column` | 116 | 指定欄位名稱、長度、能不能是 null |
| `@Enumerated` | 15 | enum 存進資料庫的方式（通常存成文字） |
| `@ManyToOne` | 23 | 多對一關聯，例：多筆訂單明細屬於一張訂單 |
| `@OneToMany` | 2 | 一對多關聯（例：`Coupon` 對它發出去的每一張 `MemberCoupon`） |
| `@ManyToMany` | 2 | 多對多關聯（`Product` ↔ 風格、`CouponSchedule` ↔ 指定會員） |
| `@JoinColumn` | 27 | 指定外鍵欄位名稱 |
| `@JoinTable` | 2 | 多對多時指定中間表 |
