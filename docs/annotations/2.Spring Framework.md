# Spring Framework

## 2-1 讓 Spring 建立、管理物件（bean）

| 註解 | 次數 | 用途 |
|------|------|------|
| `@Component` | 11 | 一般元件，Spring 啟動時會建立它的物件（例：`DataSeeder`、`JwtAuthFilter`） |
| `@Service` | 29 | 同 `@Component`，只是標明「這是 Service 層」 |
| `@Controller` | 1 | 回傳網頁的 Controller（只有 `SpaForwardController`，把前端路由轉給 `index.html`） |
| `@RestController` | 24 | 回傳 JSON 的 Controller（= `@Controller` + 回傳值自動轉 JSON） |
| `@RestControllerAdvice` | 1 | 全部 Controller 共用的例外處理（`GlobalExceptionHandler`） |
| `@Configuration` | 5 | 設定類別，啟動時會被讀取（例：`WebResourceConfig`、`SecurityConfig`） |
| `@Bean` | 3 | 寫在 `@Configuration` 的方法上，方法回傳的物件交給 Spring 管理（`PasswordConfig`、`SecurityConfig`、`MultipartUploadConfig` 各一個） |
| `@Import` | 1 | 測試時指定要額外載入哪些類別（`SecurityConfigTest`） |
| `@Order` | 4 | 決定執行順序：`DataSeeder` 是 1、`DemoDataSeeder` 是 2，先匯商品才能產生訂單 |

## 2-2 注入

| 註解 | 次數 | 用途 |
|------|------|------|
| `@Autowired` | 56 | 請 Spring 把需要的物件塞進來（大多出現在測試；正式程式多半改用 Lombok 的 `@RequiredArgsConstructor`） |
| `@Value` | 16 | 從 `application.yml` 讀一個值（例：`@Value("${app.upload.product-image-dir}")`） |

> 注意：Lombok 也有一個 `@Value`，但專案裡用的全部是 Spring 的 `org.springframework.beans.factory.annotation.Value`。

## 2-3 Controller：網址對應與參數

| 註解 | 次數 | 用途 |
|------|------|------|
| `@RequestMapping` | 23 | 寫在類別上，設定整個 Controller 的網址開頭（例：`/api/admin/coupons`） |
| `@GetMapping` | 49 | 處理 GET 請求（查詢） |
| `@PostMapping` | 20 | 處理 POST 請求（新增） |
| `@PatchMapping` | 18 | 處理 PATCH 請求（修改部分欄位） |
| `@PutMapping` | 5 | 處理 PUT 請求（整筆修改） |
| `@DeleteMapping` | 3 | 處理 DELETE 請求（刪除） |
| `@PathVariable` | 35 | 取網址路徑裡的值，例：`/products/{id}` 的 `id` |
| `@RequestParam` | 31 | 取網址 `?` 後面的參數，例：`?page=2` |
| `@RequestBody` | 27 | 把前端送來的 JSON 轉成 Java 物件 |
| `@RequestPart` | 1 | 取上傳表單（multipart）裡的檔案（`AdminProductController` 上傳商品圖片） |
| `@ModelAttribute` | 2 | 把多個 `?` 參數一次裝進一個物件（例：`ProductFilterRequest`） |
| `@ResponseStatus` | 27 | 指定回應的 HTTP 狀態碼，例：新增成功回 `201 CREATED` |
| `@ExceptionHandler` | 5 | 指定某種例外要由哪個方法處理（在 `GlobalExceptionHandler`） |
| `@DateTimeFormat` | 4 | 告訴 Spring 網址參數裡的日期是什麼格式 |

## 2-4 交易與排程

| 註解 | 次數 | 用途 |
|------|------|------|
| `@Transactional` | 96 | 方法裡的資料庫操作要嘛全部成功、要嘛全部取消（例：結帳時扣庫存 + 建訂單） |
| `@EnableScheduling` | 1 | 開啟排程功能（寫在 `UniclothApplication`） |
| `@Scheduled` | 5 | 定時執行的方法（例：`OrderTimeoutScheduler` 每 10 分鐘取消逾時訂單） |

> 專案用的是 Spring 的 `org.springframework.transaction.annotation.Transactional`，不是 `jakarta.transaction.Transactional`。
