# springdoc / Swagger：API 文件

| 註解 | 次數 | 來源 | 用途 |
|------|------|------|------|
| `@ParameterObject` | 12 | springdoc | 讓 Swagger UI 把一個物件拆成多個 `?` 參數顯示 |
| `@OpenAPIDefinition` | 1 | Swagger（io.swagger） | 整份 API 文件的設定（`OpenApiConfig`） |
| `@SecurityScheme` | 1 | Swagger（io.swagger） | 告訴 Swagger UI 要用 JWT（Bearer token）登入 |
| `@SecurityRequirement` | 1 | Swagger（io.swagger） | 指定 API 需要帶 token |
