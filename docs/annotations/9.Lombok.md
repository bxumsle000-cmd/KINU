# Lombok：編譯時自動產生程式碼

| 註解 | 次數 | 自動產生什麼 |
|------|------|-------------|
| `@Getter` | 33 | 所有欄位的 getter |
| `@Setter` | 19 | 所有欄位的 setter |
| `@NoArgsConstructor` | 19 | 沒有參數的建構子（JPA 的 Entity 一定要有） |
| `@AllArgsConstructor` | 19 | 包含所有欄位的建構子 |
| `@RequiredArgsConstructor` | 81 | 只包含 `final` 欄位的建構子，Spring 會用它注入依賴（正式程式主要的注入方式） |
| `@Builder` | 33 | 可以用 `Xxx.builder().name("a").build()` 的方式建立物件 |
| `@Slf4j` | 13 | 自動產生一個 `log` 變數，可以直接 `log.info(...)` |

> Lombok 不是 Spring 的。它在**編譯時**把程式碼補進 `.class` 檔，執行時已經沒有 Lombok 的事了。
