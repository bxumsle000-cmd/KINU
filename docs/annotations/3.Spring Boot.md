# Spring Boot

| 註解 | 次數 | 用途 |
|------|------|------|
| `@SpringBootApplication` | 1 | 程式進入點，開啟自動設定和元件掃描（`UniclothApplication`） |
| `@ConfigurationProperties` | 2 | 把 `application.yml` 一整段設定裝進一個物件（`JwtProperties` 讀 `jwt.*`） |
| `@ConfigurationPropertiesScan` | 2 | 自動找出有 `@ConfigurationProperties` 的類別 |
| `@EnableConfigurationProperties` | 1 | 指定要啟用哪個 `@ConfigurationProperties` 類別 |
| `@ConditionalOnProperty` | 2 | 設定值符合才建立這個物件（例：`app.seed.products: true` 才執行 `DataSeeder`） |
