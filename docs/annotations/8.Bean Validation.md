# Bean Validation（Jakarta Validation）：檢查輸入資料

| 註解 | 次數 | 用途 |
|------|------|------|
| `@Valid` | 31 | 寫在 Controller 參數前，要求 Spring 檢查這個物件裡的驗證註解 |
| `@NotNull` | 30 | 不能是 null |
| `@NotBlank` | 36 | 字串不能是 null、空字串或全空白 |
| `@NotEmpty` | 7 | 字串或清單不能是 null 或空的 |
| `@Size` | 29 | 長度範圍，例：`@Size(max = 100)` |
| `@Min` | 8 | 數字最小值 |
| `@Positive` | 8 | 必須大於 0 |
| `@PositiveOrZero` | 2 | 必須大於等於 0 |
| `@Pattern` | 5 | 必須符合正規表示式（例：性別只能是 male 或 female、客服單分類只能是固定幾種） |
| `@Email` | 3 | 必須是 email 格式 |
| `@Past` | 1 | 日期必須在過去（`CompleteProfileRequest` 的生日） |
| `@Future` | 1 | 日期必須在未來（`UpdateProductScheduledOffAtRequest` 的預定下架時間） |

> 檢查失敗時 Spring 會丟例外，由 `GlobalExceptionHandler` 轉成 400 錯誤回給前端。
