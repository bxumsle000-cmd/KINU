# V1__init.sql 用到的 SQL 技術

真正的檔案：`src/main/resources/db/migration/V1__init.sql`（PostgreSQL）

> 商品風格（styles 等四張表）、會員瀏覽紀錄（member_product_views）、HOT 標籤（products.is_hot）已在 `V2__drop_recommendation_style_hot.sql` 移除，這份整理不再列出只有它們用到的寫法。

## 資料型別

| 型別 | 用在哪 |
|------|--------|
| 大整數 | 主鍵、外鍵 |
| 一般整數 | 價格、庫存、數量 |
| 有長度上限的字串 | 名稱、代碼、狀態 |
| 不限長度的文字 | 商品描述 |
| 布林 | 是否新品 |
| 日期 | 生日 |
| 日期加時間 | 預定下架時間 |
| 日期加時間（只到秒） | 建立時間、付款時間 |

## 欄位設定

| 技術 | 用在哪 |
|------|--------|
| 必填 / 可空 | 一開始就有的值必填；之後才有的值可空（付款時間、物流單號） |
| 預設值（布林） | 新品標籤預設否 |
| 預設值（字串） | 狀態預設為初始狀態 |
| 預設值（數字） | 折扣預設 0、運費預設 50 |
| 預設為目前時間 | 建立時間 |
| 自動編號 | 每張表的主鍵 |

## 約束

| 技術 | 用在哪 |
|------|--------|
| 主鍵 | 每張表 |
| 複合主鍵 | 預約發券對象 |
| 主鍵兼外鍵（一對一） | 會員個人資料 |
| 單欄不重複 | 商品網址代碼、會員 email、員工帳號、訂單編號 |
| 多欄組合不重複 | 商品＋顏色＋尺寸、會員＋購物車 SKU、會員＋追蹤商品 |
| 外鍵 | 商品指向分類等 |
| 自我參照外鍵 | 分類的上層分類 |
| 刪除時一起刪 | 會員 → 購物車、追蹤清單、個人資料；訂單 → 訂單明細 |
| 刪除時改成空值 | SKU → 訂單明細、庫存異動明細 |
| 有人參照就不准刪 | 會員 → 訂單 |
| 檢查：只能是固定幾個值 | 庫存異動類型 |
| 檢查：不能小於 0 | 付款金額、異動前後庫存 |
| 檢查：不能等於 0 | 庫存變化量 |
| 替約束取名字 | 所有約束（主鍵、外鍵、不重複、檢查各有固定前綴） |

## 索引

| 技術 | 用在哪 |
|------|--------|
| 單欄索引 | 外鍵欄位、商品名稱 |
| 多欄索引 | 會員＋建立時間、狀態＋建立時間 |
| 指定由大到小排序 | 最新的訂單 |
| 部分索引（只放符合條件的列） | 有設定預定下架時間的商品 |
| 唯一索引＋部分條件（有值才不能重複） | Google 帳號 uid、分類代碼 |

## 修改表

| 技術 | 用在哪 |
|------|--------|
| 建表後再補外鍵 | 會員折價券 ↔ 訂單（互相參照） |

## 新增資料

| 技術 | 用在哪 |
|------|--------|
| 新增一筆 | 測試折價券 |
| 一次新增多筆 | 五個員工帳號 |

## 設計習慣

| 習慣 | 用在哪 |
|------|--------|
| 狀態存英文代碼字串 | 所有狀態欄位（對應 Java enum） |
| 快照欄位 | 訂單明細、庫存異動明細 |
| 多對多用中間表 | 預約發券 ↔ 指定會員 |
| 用「有沒有那筆資料」表示狀態 | 有個人資料 = 資料已補齊 |
| 金額用整數 | 所有金額（新台幣元） |
| 被參照的表先建、種子資料放最後 | 整支檔案的順序 |

## Flyway

| 規則 | 說明 |
|------|------|
| 檔名格式 | 版本號開頭、兩個底線、說明 |
| 跑過不能改 | 檢查碼不符會啟動失敗 |
| 要改就加新版本 | 新增下一個版本號的檔案 |
